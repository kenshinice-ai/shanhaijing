## 2. 原文自带的两处计数差异（实测，必须裁决）

各山系结语相加与总结语对不上：

| | 山数 | 里数 |
|---|---|---|
| 西山经之首（钱来之山→騩山） | 19 | 2,957 |
| 西次二经（钤山→莱山） | 17 | 4,140 |
| 西次三经（崇吾之山→翼望之山） | 23 | 6,744 |
| 西次四经（阴山→崦嵫之山） | 19 | 3,680 |
| **相加** | **78** | **17,521** |
| **总结语「右西经之山」** | **77** | **17,517** |
| **差** | **1 山** | **4 里** |

《南山经》已经确立了「计数差异逐条登记、不静默修正」的做法，此处沿用即可，
但**差异归因需要编辑裁决**：是传抄脱漏、是结语统计口径不同（例如是否计入某山两见），
还是原文本身如此。这是本篇最具学术风险的一处，建议在会上单独占一项。

## 4. 关键发现：ctext 与维基文库有 52/82 段存在文字差异（实测）

去掉郭璞注后逐段比对，**82 段中有 52 段不完全一致**。抽样归类：

| 类型 | 例 | 建议处理 |
|---|---|---|
| 异体字 | 花／華、鱉／鼈、囂／嚻 | **不算异文**，按底本印刷形态照录 |
| 嵌入式校语 | 「逐<u>一作遂</u>水出焉」「猛豹<u>一作虎</u>」 | 剥离出来登记为 variant，不进 baseline 正文 |
| 实质异文 | 待逐条判读 | 按 `CORPUS_AND_EDITORIAL_POLICY.md` §5 建 editorial decision |

《南山经》最终只需两处裁定，是因为那 43 段里此类分歧少；西山经的 52 段差异
**绝大多数应属前两类**。若不先定「异体字不算异文」的政策，这一篇会凭空产生
几十条无意义的 variant 记录，把真正的分歧淹掉。

## 5. 推荐方案

**A 作底本 + B 作校核源 + C 作争议仲裁**，与《南山经》完全同法：

1. **底本**：ctext 白文，理由是与已冻结的南山经**同源**——五藏山经共用一个版本谱系，
   否则跨篇的段落切分与用字风格会出现无法解释的跳变。
2. **校核**：维基文库（剥离郭璞注后比对），差异按 §4 三类处理。
3. **仲裁**：实质分歧查郝懿行《山海经笺疏》扫描本，裁定写入 decision log。
4. **郭璞注**：**本轮不入库**，但建议登记为下一阶段的独立层
   （`interpretation_class = commentary`），它是现成的、公版的、与经文逐句对应的注释层，
   本项目的证据模型天然容得下它。
5. **segmentation**：沿用 `nanshan-full-v2` 规则，版本号定为 `xishan-full-v1`。

**代价**：约 82 段的逐段审核 + 52 段的差异判读 + 22 个生僻字的字体子集重做 +
两处计数差异的裁定。生成器、verifier、词表与前端**不需要改**——
分类词表可能需要为新出现的异兽形态增补词条，那是加数据不是改结构。
