# 母图画风对比与择优

- 日期：2026-08-18
- 生成命令：`npm run generate:overview -- --variant=<handscroll|mineral|ink>`
- 结论：**采用 C · 水墨**（生成器默认值 `ink`）

三版共用**同一套几何**——山簇、水系、海岸线全部由语料与拓扑推导，换的只有颜色与笔触。
因此比较的是「哪一版更压得住叠加层」，不是「哪一版把地理画得更对」。

## 判据

母图的职责是背景。它上面要落 39 个热点、39 个山名与 36 条里距，共 94 个标签；
**地面越吵，证据越难读**。所以除了目测，还量了标签实际落区（陆地带 840×420）的像素分布：

| 画风 | 平均亮度 | 亮度标准差（噪声） | 与标签抢对比的亮像素 |
|---|---|---|---|
| A · 手卷（原版） | 100.4 | 18.9 | 2.30% |
| B · 青绿 | 109.5 | 21.1 | **5.47%** |
| **C · 水墨（采用）** | **94.4** | **18.4** | **1.42%** |

标签色为 `#FFF3CD` 的浅金。B 版矿物石青石绿单看最漂亮，但陆地明度抬高、亮像素接近 A 版的
两倍半、C 版的四倍——**它是三版里最好看的，也是最不适合当背景的**。

C 版陆地压到最暗且噪声最低，山簇与水系仍然清晰可辨，热点金环与标签浮得起来。

## 保留

三套调色板都留在 `scripts/generate_overview.ts` 的 `PALETTES` 里，可随时重出比较；
比较用产物走 `--out` 参数，**不写 manifest**，以免污染已发布资产的记录。

## 影响

母图内容改变，checksum 随之更新——这是新版本资产，不是回归。几何、
段落映射与 hotspot 坐标一字未动，因此 parity 与领域校验不受影响。
